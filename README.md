### Experiment ordering

- Experiment IDs use `exp-rts-NNN-description`.
- `NNN` is a zero-padded sequence number.
- Read experiments in ascending numeric order.
- [`exp-rts-001-thousand-turn-match`](./age-of-llms/experiments/exp-rts-001-thousand-turn-match.md) is the first ordered run. Petra led after 1,000 RL turns.
