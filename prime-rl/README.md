# PrimeRL experiments

Environments, training recipes, and questionable amounts of reward hacking built with [PrimeRL](https://docs.primeintellect.ai/prime-rl/overview).

## Experiments

- [The Scientist](./the-scientist/) — can outcome-based RL teach a small language model to discover laws by choosing informative experiments?

Each experiment keeps its idea, build plan, method, verification protocol, and hypotheses beside the code so the science does not get lost in the GPU smoke.
